# Публикация «Сметочка» в Google Play

Краткий чеклист для релиза в [Google Play Console](https://play.google.com/console).

**Текущая версия в репозитории:** `1.1.0+2` (`versionName` 1.1.0, `versionCode` 2)

## 1. Подпись приложения

Release подписывается upload keystore (`android/key.properties`, `android/upload-keystore.jks`). Файлы **не коммитить**.

Создание keystore (один раз): см. `key.properties.example` и раздел в истории репозитория.

## 2. Сборка AAB

```bash
./scripts/build_play_bundle.sh
```

или:

```bash
flutter pub get
flutter build appbundle --release
```

Готовый файл: `build/app/outputs/bundle/release/app-release.aab`

## 3. Версия

В `pubspec.yaml`:

```yaml
version: 1.1.0+2
```

- `1.1.0` — `versionName` (для пользователя)
- `2` — `versionCode` (**увеличивать** при каждой загрузке в Play)

Следующий релиз, например: `1.1.1+3`.

## 4. Идентификатор пакета

`com.remontestimate.remont_estimate` — **не менять** после публикации.

### Полное описание (RU)

```
Сметочка — смета ремонта квартиры или дома без таблиц вручную.

• Несколько проектов (квартира, дача и т.д.)
• Комнаты и материалы: цена, количество, фото, бренд, магазин
• Отметка «куплено» и отдельный учёт потраченной суммы

Без входа данные хранятся только на телефоне. Вход в аккаунт — по желанию, для синхронизации и восстановления после переустановки.
```

## 6. Безопасность данных (Data safety)

Заполните анкету с учётом **Firebase** (если пользователь входит в аккаунт):

| Вопрос | Ответ |
|--------|--------|
| Собираются ли данные? | **Да** (опционально, при входе в аккаунт) |
| Типы данных | Email (аккаунт); пользовательский контент (смета, фото материалов) |
| Цель | Функции приложения, резервное копирование |
| Передача третьим лицам | **Да** — обработчик **Google Firebase** (Auth, Firestore, Storage) |
| Шифрование при передаче | **Да** |
| Удаление | Пользователь может выйти из аккаунта; запрос удаления облака — email разработчика (см. политику) |
| Обязательный сбор | **Нет** — можно пользоваться без регистрации |
| Реклама | **Нет** |

Локальные данные (без входа) остаются на устройстве; в анкете укажите, что облако — **по выбору пользователя**.

## 11. Частые ошибки

- APK вместо AAB → `flutter build appbundle`
- `versionCode` не увеличили → отклонят обновление
- Потерян `upload-keystore.jks` → нельзя обновить то же приложение
- `Given final block not properly padded` → неверные пароли в `key.properties`
