2. Краткое резюме

  • Можно пользоваться без регистрации — данные только на устройстве.
  • По желанию — вход (Google или email) и резервная копия в облаке (Google Firebase).

4. Облачная синхронизация (Firebase)

Если вы входите в аккаунт, для резервного копирования используются сервисы Google Firebase (проект разработчика):

  • Firebase Authentication — вход через Google или email/пароль;
  • Cloud Firestore — JSON ваших проектов и материалов, привязанный к вашему идентификатору;
  • Firebase Storage — фотографии материалов, привязанные к вашему аккаунту.

Доступ к облачным данным возможен только после аутентификации под вашим аккаунтом. Передача между приложением и Firebase шифруется (HTTPS/TLS).

Политика Google: Firebase Privacy, Google Privacy Policy.

Данные не продаются рекламным сетям. Передача возможна:

  • Google Firebase — при вашем входе в аккаунт (см. раздел 4);
  • при использовании «Поделиться», «Открыть файл», сохранения в галерею — действует политика выбранного вами приложения.
